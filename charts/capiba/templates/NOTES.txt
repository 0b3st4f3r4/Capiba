Persistência:
  {{ .Values.global.dataPath }} é a raiz do MinIO: cada subdiretório de
  primeiro nível é um bucket (capiba-bronze, capiba-silver, capiba-gold,
  capiba-artifacts, capiba-airflow-logs, capiba-backups).
  ArangoDB e PostgreSQL usam PVs hostPath gerenciados pelo chart em:
    {{ .Values.global.servicesDataPath }}
  Compacte as pastas data/ e services/ para migrar/distribuir o
  ambiente (ex: via FSX).

  Buckets: crie o layout completo com "make init-buckets".
  Código e DAGs do Airflow: publique com "make publish-artifacts"
  (bucket capiba-artifacts, sem rebuild de imagem).

  Todos os PVCs possuem helm.sh/resource-policy: keep, portanto NÃO são
  removidos por "helm uninstall". Os PVs hostPath usam Retain, preservando
  os arquivos no host mesmo após exclusão do PVC.
